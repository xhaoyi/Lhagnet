## 安装

1. 把 APK 传到手机
2. 允许「安装未知来源应用」
3. 安装后到「设置 → 无障碍 → 已下载的服务」启用「风车」
4. 首次打开需注册 / 登录；随后到「模型」里选本地模型或填云端 API Key

## 系统要求

- Android 10（API 29）及以上，仅 `arm64-v8a`
- minSdk 26 / targetSdk 35
- 需要授权：无障碍服务、悬浮窗、通知；Android 10 及以下截图需录屏投射
- 本地大模型建议可用内存 ≥ 模型体积 × 2（2B 约 1.4GB 起，4B 需 8GB 内存）

## 隐私说明

- 界面识别与点击全部在本机完成；本地模型推理不联网
- 不采集 IMEI / MEID / 序列号
- 反馈功能仅在**主动点击「发送反馈」**时上传日志与设备信息 —— 详见仓库 `SECURITY.md`

## 已知限制

- 美团 / 饿了么的选店、选规格、加购仍依赖对方真实界面，部分机型会卡在加购前
- 4B 及以上模型需 8GB 内存，6GB 机型建议 Qwen3-VL-2B（约 1.4GB）
- 仅 arm64-v8a，未 Root
