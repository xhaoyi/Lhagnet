# 风车 v1.0.0

发布日期：2026-10-26

Android 辅助操作 App —— 用无障碍服务读取屏幕控件并执行点击/输入，代替你手动操作其他 App。

## 安装

1. 把 APK 传到手机
2. 允许「安装未知来源应用」
3. 安装后到「设置 → 无障碍 → 已下载的服务」里启用「风车」
4. 首次使用会在「设置 → 模型」里要求填入 API Key 与后端地址

## 系统要求

- Android 8.0（API 26）及以上
- 需要授予：悬浮窗权限、无障碍服务、通知权限

## 隐私说明

- 屏幕读取与点击操作全部在本机完成，数据只在本机处理
- 不采集 IMEI / MEID / 序列号
- 反馈功能在**你主动点击「发送反馈」**时，才会把运行日志与设备信息上传到服务器 —— 详见仓库内的 `SECURITY.md`

## 功能

- 聊天式任务：说一句话，App 帮你操作目标 App
- 技能（Skills）：内置导航、购物、网页、拼多多等技能包
- 记忆（Memory）：跨会话保留常用信息
- 定时任务：到点自动执行
- 灵动岛：顶部胶囊显示运行状态与进度
- 多语言 / 字体缩放 / 明暗主题
